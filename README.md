# Selenium Website Automation

Python Selenium automation project for testing the SnowTechLabs contact form.

## Tech Stack

- Python
- Selenium WebDriver
- Google Chrome
- VS Code

## Test Scenario

1. Open SnowTechLabs website
2. Click Get Started
3. Enter name
4. Enter email
5. Enter company
6. Enter phone
7. Enter message
8. Select budget
9. Click Send Message

## Installation

Install Selenium:

pip install selenium

## Run Test

python test_contact_form.py
